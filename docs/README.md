# Loadika Desktop — документация

Loadika Desktop — кроссплатформенное (Linux / Windows / macOS) десктопное приложение —
удобная обёртка над [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) с:

- сохранением типовых настроек загрузки (пресеты);
- пулом прокси с автоматическим переключением при сбоях;
- выбором папки загрузки;
- управлением зависимостями (`yt-dlp`, `ffmpeg`/`ffprobe`, JS-рантайм `deno`):
  обнаружение, установка и обновление.

## Стек (кратко)

| Слой | Технология |
|------|-----------|
| Desktop-оболочка | Wails v3 (нативный webview, один лёгкий бинарник) |
| Бэкенд | Go |
| Фронтенд | Vue 3 (Composition API) + TypeScript (strict) |
| Сборка фронтенда | Vite |
| Состояние | Pinia (лёгкая) |
| UI | собственные компоненты на CSS-токенах + headless `reka-ui` для сложных примитивов |
| Пакетный менеджер | npm |

Точные версии и обоснование — в [`01-tech-stack.md`](./01-tech-stack.md).
