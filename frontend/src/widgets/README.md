# widgets

Составные блоки интерфейса, собирающие `features` и `entities` (например, `sidebar`, `task-list`).

Реализовано: `deps-status` — компактный чеклист зависимостей на главной («Проверить все»
и «Удалить загруженные»); `deps-detail` — детальный блок на вкладке «Зависимости» в «Настройках».
Остальные наполняются по мере развития (см. `docs/03-frontend-fsd.md`).
